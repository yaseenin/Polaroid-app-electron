# Polaroid Print Imposition Engine

This Rust crate contains an initial `eframe`/`egui` shell for the Polaroid print imposition tool described in the project specification.

## Features included

- split-screen layout with left control panel and live preview canvas
- preset, paper, and export option controls
- adjustable nudge and image filter settings
- file chooser placeholder for photo selection
- structure aligned with the requested worker-thread and non-destructive editing model

## Run

```bash
cargo run --manifest-path rust/Cargo.toml
```
